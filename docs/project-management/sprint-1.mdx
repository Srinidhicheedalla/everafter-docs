# Sprint 1 – Documentation Website Setup

**Sprint Duration:** 1 Week

**Sprint Goal:** Build the initial EverAfter Documentation website.

## 1. Sprint Objective

To create a structured, user-friendly documentation website using Docusaurus.

## 2. Planned Tasks

- Set up the Docusaurus project.
- Design the homepage.
- Create the EverAfter logo and colour theme.
- Organize documentation using sidebar navigation.
- Create user guides.
- Add helpful documentation elements.

## 3. Completed Tasks

- Successfully configured Docusaurus.
- Created and customized the homepage.
- Added EverAfter branding and logo.
- Created Getting Started documentation.
- Added registration, login and password recovery guides.
- Created the Installation Guide.
- Created Release Notes.
- Added Note, Tip, Warning and Danger elements.
- Published the website using Vercel.

## 4. Sprint Outcome

A functional documentation website with organized content, consistent branding and easy navigation.

## 5. Future Improvements

- Add screenshots to user guides.
- Improve the documentation layout.
- Review content for clarity and accuracy.
- Add more product-related documentation.

## 6. What I Learned

- Docusaurus project structure.
- Markdown and MDX documentation.
- Sidebar navigation.
- Documentation organization.
- Website deployment using Vercel.
- Basic Agile Sprint documentation.

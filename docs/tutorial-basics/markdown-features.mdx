# Markdown Features

Markdown helps technical writers create clear and well-structured documentation.

## 1. Headings

Use `#` symbols to create headings and organize content.

```md
# Main Heading
## Subheading
### Smaller Heading
```

## 2. Links

Use Markdown links to connect related documentation pages or websites.

```md
[Getting Started](../getting-started/overview)
```

## 3. Images

Images can be added using Markdown syntax. Store image files inside the `static/img` folder.

```md
![Example image](/img/everafter-banner.jpg)
```

## 4. Code Blocks

Code blocks display technical examples with formatting.

```jsx
function Hello() {
  return <h1>Hello, EverAfter!</h1>;
}
```

## 5. Admonitions

Admonitions highlight important information.

:::tip Helpful Tip

Read each instruction carefully before continuing.

:::

:::warning Important

Check the required settings before making changes.

:::

## 6. MDX and React Components

MDX allows writers to use React components inside documentation.

This makes documentation more interactive and flexible.

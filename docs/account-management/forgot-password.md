# Forgot Password

## Overview

This guide explains the password recovery
process for EverAfter users.

## Steps

1. Open the Login page.
2. Select Forgot Password.
3. Enter your registered email address.
4. Follow the password recovery instructions.
5. Set a new password if prompted.

## Expected Result

The user should be able to reset their
password and access their account.

## Troubleshooting

| Issue | Suggested Solution |
|---|---|
| Email not received | Check the spam folder |
| Invalid email | Verify the registered email |
| Reset unsuccessful | Try the recovery process again |
